# Alice·空间伙伴 0.1.0 — 角色基础体验

下载 **AliceVision-iPhone-unsigned.ipa**，用你的证书重新签名安装。本包是真机 ARM64，
不是模拟器包，也不能直接点击安装。仅支持带 LiDAR 的 iPhone Pro / iPad Pro。

## 本次新增

- 正式主屏名字与原创图标。
- 内置原创“小光”：默认 35 cm，支持待机、关节挥手和迈步测试。
- “导入角色”按钮：从“文件”选择 USDZ、DAE、OBJ、GLB 或 VRM，自动处理大小与脚底位置。
- 简化操作：扫描 → 点击蓝色平面放置 → 再点同一平面选目标 → 角色动作中确认移动。
- 大小、朝向、停止、重新扫描，以及调试和帮助入口。

GLB / VRM 目前是基础贴图与静态初始姿态展示，**不播放导入模型的骨骼行走、表情或物理**。
导入模型不会凭空生成步态；选点移动可能表现为空间平移。USDZ / DAE 的命名动画可以手动
选择一次播放，但动画本身可能有位移，不属于路线检查。完整寻路与 AI 以后再做。

阿罗娜等第三方模型需遵守作者许可，由你自行导入。**公开包没有捆绑受限阿罗娜模型**。
相机和 LiDAR 数据只在本机处理，没有 API 请求、照片上传或 AI 自动操作。

选点移动最多 1.5 米，只支持同一已扫描平面；未扫描或可能被阻挡时会拒绝/停止。
这个保守检查不能用于现实安全导航，镜面、透明物体、暗光和追踪误差仍可能产生遮挡问题。

每次发布均进行源码测试、macOS/Xcode 原生真机编译和 IPA 包检查。实际模型外观、摄像头、
朝向、后台恢复仍需要你的 iPhone 测试。当前使用 Xcode 26.2 / .NET iOS SDK，不把构建成功
当作用户报告的 iOS 27 真机兼容性验证。反馈请附完整系统版本、构建号和复现步骤。
