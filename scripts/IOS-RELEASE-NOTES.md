# AliceVision iPhone 测试版

下载 **AliceVision-iPhone-unsigned.ipa**，使用你自己的有效证书或个人开发者签名工具重新签名后安装。这个文件是供真机测试的未签名 ARM64 安装包，不能直接点击安装，也不是 App Store / TestFlight 分发包。

本版针对具备 **LiDAR** 的 iPhone / iPad，使用原生 ARKit 后置摄像头、水平面检测和 LiDAR 场景网格，作为空间感知测试。当前测试重点是用户的 iPhone 15 Pro；单摄视觉算法暂不启用。首次启动需要允许相机权限；若拒绝，可在系统设置中重新开启。摄像头及深度数据在设备本地处理。

水平面可能是地板或桌面，扫描时请缓慢移动设备。当前版本用于验证空间追踪、平面、网格和深度接入，尚无完整 AI 对话或二次元角色；未在你的设备上实际运行过。本安装包使用 Xcode 26.2 / .NET iOS 26.2 SDK 编译，不能把编译成功当作 iOS 27 真机兼容性验证。

请重点测试：

1. 竖屏启动，然后分别向左、向右转为横屏，检查画面及空间提示方向是否一致。
2. 对准地面、桌面和家具缓慢移动，检查平面、网格和深度状态更新。
3. 锁屏/解锁、切到后台再返回，检查相机能否恢复。
4. 如有问题，反馈 iPhone 型号、iOS 版本、发生步骤和本发布页显示的构建版本；录屏有助于复现。

每次发布先运行共享算法测试，再在 GitHub 的 macOS 构建机上完成 iPhone ARM64 原生编译，检查 IPA 目录、可执行文件、相机权限、方向声明和校验和。仍需要你的 iPhone 真机验证实际摄像头和设备兼容性。
