# Alice·空间伙伴 0.2.2 — 复杂骨骼与大网格兼容

下载 **AliceVision-iPhone-unsigned.ipa**，用你的证书重新签名安装。本包是真机 ARM64，
不是模拟器包，也不能直接点击安装。仅支持带 LiDAR 的 iPhone Pro / iPad Pro。

## 本次新增

- 复杂 GLB / VRM 单个蒙皮绑定上限由 256 提升至 **1024 根骨骼**，修复有效模型的辅助骨骼被旧数量限制误拒绝。
- 几何安全上限提升为 **200 万顶点、400 万三角形**；先估算网格数组、CPU/GPU 和骨骼矩阵内存，再读取大网格。
- 分部件检查内存并响应取消；逆绑定矩阵只读取有效骨骼对应的部分，避免无用尾部数据放大内存。
- 保留原始 UInt16 索引、逆绑定矩阵、有效权重、网格与贴图；不删减骨骼或降低画质。
- 结构超限提示具体字段、实际数量与安全上限；字段类型错误单独提示，不再只有泛化的数组错误。

## 保留的原画质内存保护

- 修复多张 4K 贴图触发旧“模型纹理解码尺寸超过预算”的问题；不再以固定原始总像素阈值判断设备容量。
- 移除 1024 缩图：GLB / VRM 使用原始分辨率 PNG/JPEG，不自动降画质、不重压缩、不改源文件。
- 编码贴图按需逐张读取，实际使用的图片共享解码；增加原画质导入进度与取消处理。
- 按应用当前内存余量检查 CPU / GPU / mipmap 与临时开销，保留安全余量；不足时明确拒绝而不是强行加载。
- 系统内存警告会停止导入、暂停 AI 并卸载大模型保护应用。内存保护不是任意 1 GB 模型可加载的保证。

## 保留的基础功能

- 模型单文件上限提高到 **1 GB（1024 MB）**；GLB / VRM 按需读取，仍保留几何/纹理预算。巨大文件不保证可渲染。
- 通用 VRM0/1 人形骨骼驱动：招呼、左右手招手、欢迎、点头、鞠躬、舞动和迈步，按实际骨骼能力显示。
- 自行导入自己的 USDZ / DAE / OBJ / GLB / VRM，不针对特定第三方角色硬编码。
- 自定义视觉 API、OpenRouter、Google Gemini 兼容接口；主动获取模型列表或手填模型 ID，Key 存本机钥匙串。
- 绿色活动区、红色禁区：在已扫描的同一平面点击 3–12 点画边界。
- 明确同意后，AI 周期观察当前视图并自主选择合法动作；常驻红色急停可停止上传与动作。

扫描 → 导入自己的模型 → 点击放置 → “更多”配置 API 并画活动区/禁区 → “启动 AI”确认。
不配置 API 也能显示模型、手动做动作。AI 必须使用支持图像输入的模型。
骨骼动作是程序化动作，不是动作捕捉/生成式动画；未识别人形映射的模型可能只能显示或平移。
GLB 原生动画片段、表情、弹簧物理和完整 MToon 不在本版范围。

第三方模型需遵守作者许可，由你自行导入，**公开包不包含受限第三方角色**。
AI 默认每 15 秒上传一张最长边 768 像素的当前 AR 画面，仅发送到你设置的接口；第三方可能保存图像或收费。
后台、追踪异常、模型/区域变化会暂停，不自动恢复。3 次连续失败或 429 会暂停。已发送图片无法撤回。
AI 不能执行任意坐标、代码或真实设备控制。没启动 AI 时相机与 LiDAR 本机处理。

移动每段最多 1.5 米，只支持同一已扫描平面；整段路径与完整脚部半径须避开禁区。未扫描或可能被阻挡时会拒绝/停止。
这个保守检查不能用于现实安全导航，镜面、透明物体、暗光和追踪误差仍可能产生遮挡问题。

朝向、后台恢复仍需要你的 iPhone 测试。当前使用 Xcode 26.2 / .NET iOS SDK，不把构建成功
当作用户报告的 iOS 27 真机兼容性验证。反馈请附完整系统版本、构建号和复现步骤。
