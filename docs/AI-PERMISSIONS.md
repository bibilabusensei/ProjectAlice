# AI 实际能做什么

这里说明的是当前实现的权限边界，不是未来功能规划。AI 只提出一次高层动作建议；应用在本机检查权限并执行预先编写的动作。僵硬、方向不对等动画问题属于本地动作实现，不能归因于模型“自己生成了奇怪动画”。

## 已允许的操作

| 操作 | 实际实现与限制 |
| --- | --- |
| 安静待机 | `idle`，无需讲话或不停活动。 |
| 看向用户 | `look_at_user`，将角色朝向当前 AR 相机；不是眼动追踪、身份识别或人脸定位。 |
| 短姿势动作 | 协议可识别 `wave`、`wave_left`、`wave_right`、`greet`、`welcome`、`nod`、`bow`、`dance`。实际只向 AI 提供当前模型支持、应用当前启用的动作；姿势不会获得角色根节点位移权限。 |
| 在划定区域内移动 | `move_to_target`，只能选择本机生成、检查后提供的目标 ID。AI 不填写坐标、路线、速度或距离。 |
| 简短文字回复 | `say` 最多 280 字符，在应用状态栏显示；当前没有语音合成或语音识别。 |

左右招手等并不是 AI 自己控制每根骨骼。AI 选择动作名，动作的抬手方向、关节曲线、速度和过渡由本机代码负责。当前协议不允许单独发出 `walk` 或 `look`；移动时需要的行走动画由应用执行。

## 移动如何限制

用户必须先放置角色、划定绿色活动区，再明确同意启动 AI。角色的保守占地半径须完整留在区域内，并远离边界和红色禁区。当前只支持同一块已扫描水平面：高度误差不超过 5.5 厘米，单次移动不超过 1.5 米。

本机按 25 厘米间距搜寻附近、当前画面内的候选点，只向 AI 提供最多 12 个通过检查的目标。整段路线均须通过活动区、禁区、支撑平面边界和 LiDAR 网格障碍检查；移动期间继续验证。网格不完整、路线可能接触家具/墙壁或追踪不稳定时不能开始或继续移动。移动指令置信度至少为 0.65。

这不是绕障寻路、全身碰撞、布料/道具约束或现实安全保障。虚拟手臂及模型携带的物件没有独立的环境碰撞求解；传感器可能漏掉透明、反射或未扫描物体。请在空旷、光照良好场景测试。

## 明确没有开放的权限

- 任意代码、Shell、系统命令、任意工具或由 AI 指定的网络请求。
- 直接指定骨骼旋转、任意动画片段、连续每帧控制、动作循环、永久授权或后台任务。
- 随意生成移动坐标、扩大活动区、越过红色禁区、跨平面、爬楼梯或自动坐家具。
- 导入、改写、删除或上传用户的完整 VRM 文件、贴图与其他本地文件。
- 修改 API 地址、模型、Key、性格配置或向其他服务转发凭据。
- 控制 HomeKit、米家、真实灯具、门锁、电脑、游戏或其他真实设备。
- 麦克风监听、语音对话、长期记忆、后台陪伴或应用返回前台后自动恢复 AI。

“获取模型列表”是用户在设置页主动点击的独立请求，不是 AI 可以调用的工具。用户手动播放的模型内置动画也不进入 AI 动作白名单。

## 启动后发送哪些数据

默认决策间隔 15 秒，设置页允许 10–120 秒；请求进行中、角色移动中或画区域时不会叠加新的观察请求。图像是当前 **AR 场景视图**：房间摄像头背景、虚拟角色和场景中的区域标记，不是整部手机屏幕录制。最长边 768 像素、JPEG 质量参数 0.60，最多 2 MiB。

同一个请求还包含本次快照 ID、区域版本、追踪/放置状态、可用动作、目标 ID/画面位置/本机测量距离、角色设定，以及最近一个动作和截短到 140 字符的最近回复摘要。当前不发送音频、完整模型文件或完整房间网格。所选服务仍能在截图中看见用户模型，也可能看见人脸、屏幕等私密内容。

数据发送给用户填写的第三方 HTTPS 接口，服务商可能保存数据或收取费用。启用前会再次列出服务主机、模型和上传说明；不配置 API、不启动 AI 时仍可导入模型并手动操作，不会周期上传画面。

Key 保存在本机、解锁后可访问且不可跨设备同步的 iOS 钥匙串；不会退化为普通配置文件明文保存。请求将此 Key 作为 Bearer 凭据发送给用户选定的服务，禁止 HTTP 重定向以避免转发凭据。改变接口地址时，设置页清空旧 Key。

## 不可信回复与停止机制

回复必须是单个严格 JSON，只能包含固定字段和一个动作，不能混入坐标、代码、额外工具或未知字段。快照 ID、区域版本、当前动作白名单和当前场景状态会再次校验；改模型、区域或空间会话后，旧回复被丢弃。文字提示和图片里的文字不能扩大这些代码约束。

每次请求最多等待 30 秒，同一时间最多一个请求，响应总大小最多 64 KiB。HTTP 429 或连续 3 次失败会暂停 AI，需要用户重新启动。离开前台、锁屏、追踪中断、改模型/区域、手动控制、重置扫描及系统内存紧张也会暂停。

红色“急停”取消待处理请求并立即停住当前动作，不会为了恢复待机姿态继续摆手；暂停或急停后不自动重启。已经到达服务商的图片无法撤回，取消请求也不能保证服务端已经停止计算。
