# Alice·空间伙伴图标

正式图标保存在 `AliceVision.iOS/Assets.xcassets/AppIcon.appiconset/Icon1024.png`。
使用内置 imagegen 工具生成原创图像，再用 `scripts/convert-app-icon.ps1` 机械缩放为
iPhone/iPad 图标尺寸和不含 alpha 通道的 RGB PNG。并未使用任何阿罗娜素材。

## 最终生成提示词

```text
Use case: stylized-concept
Asset type: production iPhone app icon for Alice, a friendly AR spatial companion app
Primary request: one polished original app icon, an adorable tiny 3D companion face framed by a subtle luminous spatial orbit, expressing a friendly presence in real space. Simplified sculpted shapes and clear silhouette readable at 48 pixels. Inspired by the project's existing blue and white UI, not any existing trademarked character.
Composition/framing: single centered symbol with generous safety margin on an opaque edge-to-edge square background, no pre-rounded corners, 1024 by 1024 square. Soft professional 3D product render, gentle depth and controlled glow.
Constraints: no text, no letters, no mockup, no border, no watermark, no scenery, no multiple options, no transparent pixels. This image will be the real installed app icon.
```
