# AI 与活动区域

## 开始

1. 缓慢扫描 LiDAR 场景，导入自己的角色，点击蓝色水平面放置。
2. “更多 → 画活动区”：在同一平面点击 3–12 点，最后完成。绿色边界须足够大，角色整个脚部半径都在里面。
3. 可在绿色边界内部画红色禁区。禁区不可重叠、触碰外边界或跨平面。
4. “更多 → AI 模型与 API 设置”：选择服务商，填写完整 HTTPS Chat Completions URL、支持图像的模型 ID 与 Key。
5. 点击“启动 AI”，核对服务主机、模型与上传说明。同意后自主活动，不需要逐动作确认。

默认 15 秒一次，可设 10–120 秒。当前 AR 视图以最长边 768 像素、JPEG 质量 60% 发送，包含虚拟角色与区域标记。
服务商选择只是地址预设，不赠送 API，不保证免费、模型可用或数据隐私。Key 存在本机、不可同步的 iOS 钥匙串。
“获取模型列表”仅在你点击时请求此接口的 `/models`，不发送图像；OpenRouter 列表过滤为声明支持图像的模型。
自定义接口须兼容 `messages` 中的 `image_url` 与返回的 `choices[0].message.content`。

## 停止与权限

顶部红色“急停”或“暂停 AI”取消上传请求并停止动作，已发给服务商的画面无法撤回。
离开应用、锁屏、追踪不稳、修改区域、切换模型、重置扫描会暂停；回到应用需手动启动并再次同意。
重新签名后若钥匙串不可用，保存 Key 会报错，不会退化为明文文件。
连续 3 次网络/格式错误或 HTTP 429 限流会暂停，检查配置后再手动开启。

## 提示词与约束

系统提示词已内置在 `CompanionApiClient`。性格/自主目标可以填写：

> 你是温和活泼的空间伙伴。观察环境，在允许区域里偶尔散步、向我招手，空闲时安静待机。

每次接收当前快照、可用动作、本机检查的目标 ID。图像仅用于语义理解，不让模型测量距离。
回复是一次建议的严格 JSON：当前 `snapshot_id`、`action`、`target_id` 或 null、有限置信度、简短 `say`。
额外坐标、代码、循环授权、真实设备指令和过期快照均拒绝。移动置信度最低 0.65。
合法回复仍须通过最新追踪、模型/区域版本、同一平面、整个脚部半径、整段路径及 LiDAR 网格检查，移动期间继续验证。
AI 不执行模型自带的任意动画片段，只使用本应用定义的姿势动作；动画不能扩大行动权限。

## 当前边界

仅前台运行，没有后台任务、长期记忆、语音、自动坐家具、跨障碍寻路或智能家居控制。
传感器可能漏掉透明、反射、未扫描物体；区域检查不是现实安全保障，请在空旷、光照良好场景测试。
没有 Key 的真实服务测试由你安装后完成；离线测试验证协议与几何，不代表任意 API 一定兼容。

预设地址参考官方文档：[Gemini 兼容接口](https://ai.google.dev/gemini-api/docs/openai)、[OpenRouter Chat Completions](https://openrouter.ai/docs/api/api-reference/chat/create-a-chat-completion)。
